# レシート家計簿

レシートの画像をアップロードすると、Claude API（Claude Haiku 5.5）が店名・日付・商品名・金額を読み取り、カテゴリ別に自動で分類して集計する家計簿 Web アプリです。

## 主な機能

- レシート画像のアップロード（複数枚まとめて可）と自動読み取り
- 商品を自動分類（食費・外食・日用品・飲料・嗜好品・衣服・美容・医療・健康・交通費・趣味・娯楽・その他）
- カテゴリ別の円グラフ・月別の積み上げ棒グラフ（Chart.js）
- 日付・カテゴリの手動修正、レシートの削除
- データはブラウザのローカルストレージに保存（リロードしても消えない）

## 構成

| ディレクトリ | 内容 |
| --- | --- |
| `server/` | Node.js（Express）のバックエンド。Claude API を呼び出す |
| `src/` | React のフロントエンド（Vite） |
| `shared/` | フロント・バックで共有するカテゴリ定義 |

API キーはバックエンドだけが持ちます。ブラウザから Claude API を直接呼ぶことはありません。

## セットアップ

```bash
npm install
cp .env.example .env   # .env の ANTHROPIC_API_KEY に自分の API キーを設定
```

## 起動

```bash
# 開発（バックエンド :3001 とフロントエンド :5173 を同時に起動）
npm run dev
```

ブラウザで http://localhost:5173 を開きます。

```bash
# 本番（ビルドしてから Express でまとめて配信）
npm run build
npm start
```

## 注意

- 画像はアップロード前にブラウザ側で縮小（長辺 2000px）・JPEG 変換してから送信します。スマホで撮影した大きな写真もそのまま選べます。
- HEIC 画像は、ブラウザが HEIC を読み込める場合（iPhone の Safari など）のみ変換できます。読み込めない場合は JPEG に変換してからアップロードしてください。
- データはブラウザごとに保存されます。別の端末やブラウザとは共有されません。
